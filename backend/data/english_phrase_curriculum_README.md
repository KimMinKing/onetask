# English Phrase Curriculum

Generated by `backend/generate_english_phrase_curriculum.py`.

Output file:

- `backend/data/english_phrase_curriculum.csv`

Shape:

- 10 levels
- 1,000 rows per level
- 10,000 rows total

Columns:

- `id`: stable generated row id
- `level`: 1 through 10
- `cefr`: rough CEFR band
- `level_title`: level theme
- `function`: communicative function, such as asking, opinion, work, argument
- `pattern_no`: expression frame number within the level
- `variation_no`: generated variation number within the frame
- `expression`: phrase or sentence chunk to memorize
- `meaning_ko`: Korean meaning
- `example_en`: short example sentence using the chunk
- `example_ko`: Korean explanation of the example sentence
- `dialogue_en`: two-turn mini dialogue using the expression
- `dialogue_ko`: Korean translation of the mini dialogue
- `situation_ko`: usage situation
- `note_ko`: learning note for the pattern
- `memory_chunk`: expression split into memorization chunks
- `cloze_prompt`: fill-in-the-blank recall card
- `reverse_prompt_ko`: Korean-to-English recall prompt
- `memory_tip_ko`: how to memorize the expression
- `confusion_note_ko`: common mistake or grammar warning
- `review_steps_ko`: suggested review flow
- `tags`: pipe-delimited tags for filtering and card generation
- `practice_prompt_ko`: Korean prompt for active recall practice

Level design:

1. A1 survival chunks: wants, needs, choices, time, simple requests
2. A2 daily conversation patterns: plans, requests, experiences, simple opinions
3. A2+ linking ideas: contrast, condition, sequence, reasons, examples
4. B1 practical fluency: decisions, concerns, explanations, mistakes
5. B1+ work and problem solving: meetings, status, handoffs, priorities
6. B2 nuance and softening: polite requests, hedging, pushback, trade-offs
7. B2+ argument and storytelling: framing, evidence, impact, summary
8. C1- advanced discussion: nuance, critique, implications, alternatives
9. C1 professional precision: strategy, governance, evaluation, risk
10. C1+ rhetorical control: bluntness, fairness, causality, objections, synthesis

The CSV is intended as a seed dataset. Some generated rows are intentionally
pattern-like, so a later UI can group them by `pattern_no` and teach the frame
first, then drill the 50 variations.

Memorization design:

- Start with `reverse_prompt_ko` to recall the expression from meaning.
- Use `memory_chunk` to speak the expression in 2-3 rhythm groups.
- Use `cloze_prompt` as a quick blank-card drill.
- Read `confusion_note_ko` before review to prevent common grammar mistakes.
- Use `review_steps_ko` as the card workflow: meaning -> chunk -> cover -> adapt.
