# 중국어 단어 이미지 연결

기존 HSK3~6 그림은 `word_<숫자 ID>.webp`라는 이름으로 생성됐다. 이후 단어 뜻과 예문을 수정해도 이미지 파일은 그대로 남아 다른 단어의 그림이 표시될 수 있었다. 특히 HSK4 그림은 단어 데이터 재매핑 전에 생성되어 다수의 ID가 밀려 있었다.

`word_image_manifest.json`은 기존 SQL 데이터의 수정 전·후 예문을 대조해 그림의 출처를 확인한 결과다. HSK4는 원본 예문이 정확히 일치하는 그림을 새 단어에 연결하고, HSK3·5·6은 수정된 데이터와 ID가 일치하는 그림만 등록했다. 서버는 현재 단어의 HSK 급수, 한자, 병음, 뜻, 예문 지문이 목록과 모두 일치하고 실제 파일이 있을 때만 그림 URL을 내려준다. 확인되지 않은 기존 그림은 빈 상태로 표시한다. 파일 수정 시각과 크기를 URL 버전에 넣어 교체된 그림이 브라우저 캐시에 가려지지 않게 했다.

로컬 자료에서 기존 그림 4,700개 중 4,664개를 연결했다. HSK4의 35개는 원본 예문을 유일하게 대응시킬 수 없어 숨기고, HSK3의 1개는 이미지 생성 당시 예문이 현재 예문과 달라 숨긴다. 운영 DB 내용이나 이미지 파일이 로컬 자료와 다르면 추가로 숨겨질 수 있다. 배포 환경에서 `python audit_word_images.py`로 실제 확인/숨김 수를 읽기 전용으로 점검한다. `python regen_missing_images.py --dry-run`으로 재생성 대상도 확인할 수 있다. 실제 재생성은 외부 이미지 API 비용이 들므로 필요 범위를 검토한 뒤 실행한다.

앞으로 생성하는 그림은 단어 내용의 지문을 파일명에 포함한다. 단어 뜻이나 예문이 수정되면 예전 그림이 자동으로 숨겨지고, 재생성한 그림만 새 데이터에 연결된다. 그림을 복사해 배포할 때는 DB와 `backend/test_output`을 같은 버전으로 유지한다.
